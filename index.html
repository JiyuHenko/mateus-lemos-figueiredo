03 / A BIT ABOUT ME

A winding path.
That's the fun part.

Turns out being curious about everything is pretty useful when you build software for a living.

I've never been very good at leaving a problem alone just because it looks complicated.

— the short version of my personality

I started programming with C and Java, and gradually found myself building web applications, automating browsers, experimenting with AI assistants, and helping people turn vague ideas into useful products.

At Custom Mind, I've been involved in about 30 client engagements. At PRODEMGE, I work on enterprise test automation, regression investigation, and developer tooling with Playwright, JavaScript, and Go. I've also shipped applications using Docker and AWS.

I don't think a language or framework defines an engineer. I care more about understanding the system, making thoughtful trade-offs, and being able to explain why something works — or why it doesn't.
